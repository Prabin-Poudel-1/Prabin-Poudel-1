## About me

I am a Computer Engineering student in Nepal interested in **offline-first applications, backend systems, AI security, and satellite intelligence**. I focus on building working prototypes, testing their assumptions, and documenting their limitations.

- **Currently exploring:** secure AI-agent authorization, emergency coordination, and resilient mobile applications.
- **Working with:** Flutter/Dart, Java/Spring Boot, React/TypeScript, Python, Rust, and PostgreSQL.
- **Learning:** distributed systems, cloud infrastructure, and machine learning.
- **Portfolio:** [poudelprabin.com.np](https://www.poudelprabin.com.np/)
